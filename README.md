# hub-board

Les versions publiées de **hub-board** (dit « hub »), l'app Mac qui enregistre, transcrit et résume tes Google Meet sur
ton Mac, et range tes projets, ton agenda et tes mails.

- **Télécharger** : [hub-board.dmg](https://github.com/paulmailhes/hub-board-releases/releases/latest/download/hub-board.dmg)
  (macOS 27 ou plus récent, Mac à puce Apple), puis glisser hub dans Applications.
- **Mises à jour** : hub les trouve ici et s'installe seul, jamais pendant une réunion.
- **Le site** : [paulmailhes.xyz/hub-board](https://www.paulmailhes.xyz/hub-board).

Ce dépôt ne contient que les versions (l'image disque, l'archive des mises à jour et leurs notes) ; le code n'est pas
public.
